My project

My goal is to make a quadruped bot using arduino, that walks by itself, isnt remote controlled and walks around objects. 
i want it to walk smoothly and organic, and if all of this works out, i might even want it to be able to walk over rough terrain.

Why do i want to make this? 
I recently made a freenove hexapod kit, it was really fun and challenging. The only thing was, the walking didnt seem organic and very mechanical.
So i decided it would be a nice challenge to learn how to make somethign simillar, with four legs from scratch.
